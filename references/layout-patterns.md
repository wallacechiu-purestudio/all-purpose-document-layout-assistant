# 視覺系統與版型模式

## A. Editorial / E-ink
適合人文、文化、設計研究、質性研究、案例與敘事。使用大標題、留白、適量襯線字體、紀實圖片、引言與有秩序的不對稱版面。裝飾不可壓過證據；不可捏造照片或來源。

## B. Swiss / Grid
適合方法、數據、工程科技、比較、流程、模型與矩陣。建立明確網格、共同邊界、無襯線層級、有限功能色及穩定的資料視覺編碼。

## C. Workshop
適合課堂概念、示範、實作、PBL、討論與評量。明確呈現目標、任務、步驟、時間、產出物、評量標準、回饋與提交方式。

## 依頁面任務選版型
- 封面／開場：主題、脈絡、作者／課程等必要資訊。
- 論點頁：結論式標題、支持證據、解釋。
- 數據頁：一個主要比較或指標，標明單位、範圍、註解及來源。
- 方法流程：依序呈現步驟、資料來源與分析方式。
- 比較頁：以一致維度比較，避免用不同標準混比。
- 案例／圖片頁：明確說明圖片與論點的關係、圖說及來源。
- 教學任務頁：目標、操作步驟、時間、產出與評量。
- 結論頁：主要發現、貢獻、限制或下一步。

不要每頁使用相同卡片。先決定頁面任務與資訊層級，再挑選版型。單一成品保持一致的字體、色票、網格、間距與元件規則。
