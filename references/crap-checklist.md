# CRAP 兩輪檢核清單

每份成品先檢查第一輪、修正，再完成第二輪。請根據實際版面填寫狀態與證據，不可只勾選而不檢視。

## 第一輪：找問題

### C — Contrast（對比）
- [ ] 每頁／每節有明確主要焦點。
- [ ] 標題、內文、註解與來源的層級可辨識。
- [ ] 正文可讀，對比足夠；顏色不是唯一差異訊息。
- [ ] 強調色有節制，沒有多個元素同時爭奪注意力。

### R — Repetition（重複）
- [ ] 字級、字重、色彩角色與間距規則一致。
- [ ] 標題、頁碼、圖表標籤及引用格式一致。
- [ ] 同類資料使用固定顏色與符號。
- [ ] 特殊頁面的設計變化有清楚理由。

### A — Alignment（對齊）
- [ ] 標題、內文、圖片、圖表與來源有共同邊界或網格。
- [ ] 表格欄位、數字、單位與標籤對齊。
- [ ] HTML/CSS 優先使用 Grid/Flex 與共用設計變數。
- [ ] 沒有任意縮排、無意義置中或大量絕對定位造成的混亂。

### P — Proximity（親密性／群組關係）
- [ ] 標題靠近所屬內容。
- [ ] 圖表標題、圖例、單位、註解及來源靠近相應圖表。
- [ ] 相關內容成組，不同主題以留白分開。
- [ ] 沒有依賴過多框線來取代清楚分組。

## 第二輪：修正後驗收
- [ ] 已修正第一輪發現的問題。
- [ ] 重新檢查 C/R/A/P，不是只確認修改過的部分。
- [ ] 檢查文字溢位、過小字、過密頁面、斷行及列印／響應式版面。
- [ ] 內容、數據、引文與來源未被排版流程改動或捏造。
- [ ] 交付時逐項標示「通過／需修正／有條件通過」，並提供依據。
- [ ] 誠實標示尚未實際執行的瀏覽器、列印、鍵盤或視覺測試。
