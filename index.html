01 / Purpose

排版不是裝飾，
是協助理解。

服務學術簡報、教學材料、研究報告、工作坊任務與 HTML 文稿。內容正確優先於視覺效果，研究證據與原始資料不可為了版面而被改動。

02 / Visual systems

依內容選擇版型，
不讓每頁長得一樣。

A

編輯雜誌式

人文、文化、設計研究、質性案例與敘事型簡報。

B

瑞士網格式

研究方法、數據、科技、比較、流程與模型。

C

教學工作坊式

學習目標、逐步示範、PBL 任務、討論與評量。

03 / Workflow

從材料到成品的五個步驟

  1. 讀取真實素材，確認目的、受眾、限制與輸出形式。
  2. 規劃資訊架構及每頁／每節的主要訊息。
  3. 選擇一致視覺系統，依頁面任務選版型。
  4. 完成 CRAP 四原則兩輪檢查並修正。
  5. 驗證內容、來源、版面與互動，誠實揭露未測項目。
